¿Que sucedio?

Establecimos una comunicacion cliente-servidor exitosa mediante una peticion HTTP GET utilizando un fecht() hacia el backend

Conectamos correctamente al servicio y a la base de datos, obteniendo el estatus de respuesta y midiendo el tiempo de ida y vuelta (RTT)

Regresa los datos en formato JSON con la informacion de la pagina, que en este caso son lso talleres.
